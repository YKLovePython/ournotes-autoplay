## 1. 先验证"文件没被动过"

```powershell
certutil -hashfile Diting-OurNotes-Autoplay-v2.0.0-win64.zip SHA256
```

输出（去掉空格、转小写）应等于上面那串。这一步是全部时间证明的前提 ——
时间戳只对"这一串哈希"有效，所以 zip 不要再改。

（本仓库自带核对脚本，目录里所有 `.tsr` 一起验：）

```powershell
python tools\verify_timestamp.py timestamp
```

它会直接比对"文件哈希是否在 `.tsr` 里"，并打印 TSA 的签发时间。

---

## 2. 验证 RFC 3161 时间戳（`.tsr`）

要验证签名链本身（而不只是"里面有这个哈希"），需要 openssl：

```bash
openssl ts -verify -in Diting-OurNotes-Autoplay-v2.0.0-win64.zip.tsr \
                   -data Diting-OurNotes-Autoplay-v2.0.0-win64.zip \
                   -CAfile freetsa_cacert.pem -untrusted freetsa_tsa.crt
```

看到 `Verification: OK` 即通过。

---

## 3. 验证比特币时间戳（`.ots`）

```powershell
ots upgrade Diting-OurNotes-Autoplay-v2.0.0-src.zip   # 等 1~2 小时后把"待确认"升级为"已锚定"
ots verify  Diting-OurNotes-Autoplay-v2.0.0-src.zip   # 打印区块高度与区块时间
ots info    Diting-OurNotes-Autoplay-v2.0.0-src.zip.ots
```

不想装工具：把文件与 `.ots` 一起上传到 https://opentimestamps.org 在线校验。

---

## 4. 为什么两种都做

| | RFC 3161（FreeTSA） | 比特币（OpenTimestamps） |
| --- | --- | --- |
| 性质 | 权威机构签发，带 CA 链 | 去中心化，写进比特币区块 |
| 出证速度 | 秒级 | 1~2 小时（等区块） |
| 能被撤回吗 | 理论上依赖 TSA 的存续 | 不能 —— 只要比特币还在 |

两者相互独立：任何一方被质疑，另一方仍然成立。
