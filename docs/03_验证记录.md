## 怎么自己复现这些数字

```
python -c "import sys; sys.path.insert(0,'tools'); sys.path.insert(0,'src');
import human_play as hp; from bandori_autoplay.chartdb import load_events, FieldGeometry;
from pathlib import Path; geom=FieldGeometry((1280,592),2510,1156);
[hp.build_schedule(load_events(p),100.0,geom,1) for p in Path('work/chartdb/out/charts').glob('*/*.json')]"
```

（需要先按 docs 说明把全量谱面放到 `work/chartdb/out/`，本仓库只带了 1 张示例。）
