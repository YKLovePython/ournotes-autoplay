## 关键文件 SHA‑256

用于核对这份档案在之后有没有被改动（在本仓库根目录执行）：

```
powershell -Command "Get-ChildItem -Recurse -File | Where-Object { $_.FullName -notmatch '\.git\\' } | ForEach-Object { (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash + '  ' + $_.FullName.Substring((Get-Location).Path.Length+1) } | Sort-Object | Out-File -Encoding utf8 SHA256SUMS.txt"
```

## 更硬的时间证明（可选）

Git 提交时间由本机产生，权威性有限。想要第三方不可篡改的时间戳，可以：

1. 把本仓库打包成 zip，对 zip 算 SHA‑256；
2. 用 **OpenTimestamps**（免费）把该哈希锚定到比特币区块链：
   `ots stamp package.zip` → 得到一个 `.ots` 证明，之后可用 `ots verify` 校验；
3. 把 zip 与 `.ots` 文件一并交给权威机构。

这样时间证明就不依赖我们的机器和 GitHub。
