# 时间线

> English abstract: from a script that had to guess when the music starts, to one that derives its
> geometry from the game's own data — plus the two public timestamp proofs.

| 时间 | 发生了什么 |
|---|---|
| 2026-09-28 ~ 09-30 | 原型：ADB 侦察、谱面来源确认、触控通道比较（`sendevent` 被 SELinux 拒绝、`input tap` 太慢 → scrcpy-server）。写下第一版"人手起手"：你按第 1 个音符，脚本从第 2 个接手 |
| 2026-09-30 | 存档 `bang_backup_20260930_0308`：只保留"人手起手"一条线 |
| 2026-10-01 ~ 10-03 | 谱面库（our-notes-chartdb，340 张）接入；第一次公开存证：`OurNotes-Autoplay-20261003.zip`（RFC 3161 + 比特币 969627） |
| 2026-10-03 ~ 10-10 | 功能扩展期：界面、自检、更新、适配向导…… 同时也把"从画面量几何"的错误一路带进产品（见 03_验证记录.md 第 2 节） |
| 2026-10-10 | v1.0.1：一键自检；启动器 .bat 修正（CRLF + 纯 ASCII）；社区链接更新 |
| 2026-10-16 | **v2.0（本仓库）**：删掉全部外围，回到一条线；演奏区几何改为**从游戏场景数据计算**（零标定），并用 31 张实机截图复核；自检与几何核对并入 exe；便携版做成"一个 exe + 几个文件夹"，目标机器不需要 Python；重新做时间存证 |

## v2.0 与 v1.0 的差别（一句话）

v1.0 是"能跑，但要靠人量、靠猜、靠一堆外围功能"；
v2.0 只剩一条线，而这条线上每一个数都能追到出处、每一项都能被脚本复核。
