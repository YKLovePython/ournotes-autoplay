# 技术细节

> English abstract: injection over a UHID virtual touchscreen (no root), timing from the kernel
> timestamp of the player's first tap, and an action table precomputed before the tap so handover
> costs nothing.

## 1. 触控注入：UHID 虚拟触摸屏（免 root）

* 借 `scrcpy-server`（本仓库带 v4.1）在设备上 `UHID_CREATE` 一块触摸屏，
  附一份 HID 报告描述符；系统的 `dumpsys input` 里会多出一个真外设（如 `autoplay-touch`）。
* 描述符里的 Logical Maximum 用**面板自然方向（竖屏）尺寸**，Android 才会 1:1 映射；
  横屏逻辑坐标 (x, y) 转 HID 坐标是 `(panel_w − y, x)`。
* 对照实测：`sendevent` 被 SELinux 拒绝；`input tap` 每次新起进程 58~82ms 且单指 —— 都不能用于音游。

## 2. 时间轴

```
F  = 你手指真正碰到面板的内核时刻（getevent 的 [ 123.456 ]）
L  = 事件从内核读出来、经 adb 到我们手里的延迟
λ  = 我们发一条注入、到内核收到它的延迟

观测到的落指时刻 = F + L
谱面 0 点（本机） = 观测时刻 − (L + λ) − 第 1 个音符的谱面时间
```

`L + λ` 在**加载页**量（那时游戏不响应触摸）：先等一段静默，再发一条注入、回读它出现的内核事件，
取多次的**中位数**并打印全部分布（只取最小值容易被上一条事件的尾巴污染）。

## 3. 动作表（在你按下之前就算好）

三类手势：

| 类型 | 动作 |
|---|---|
| tap | 按下 → 40ms → 抬起 |
| long | 按住，并沿谱面节点轨迹**连续跟随**；到点后再多按 60ms 才松；头/尾可能是轻扫 |
| flick | 按下 → 朝谱面给的方向划出 → 抬起 |

长条跟随按**位移**重采样（走够 50px 发一次，同一根手指最快 40Hz）而不是照抄谱面节点
（节点 77~157ms 一个，单步中位位移 197px，和条子容差同量级，照抄会掉）。
手指编号按时序分配，同一根手指两次使用之间留 30ms 间隔。

因为时间轴只差一个未知量 `t0`，**整套动作表在你按下之前就算好了**（356 事件的 expert 谱约 2ms）；
按下之后只做一次"加上 t0、丢掉已经过期的动作"，接管点因此能提前到几乎不丢音符。

## 4. 几何（见 geometry/notes_geometry.json）

```
1 平面单位 = 屏高 H / 10.8 像素
x(格位 c)  = W/2 + (c − 12) × 0.64237 × H / 10.8      c = position + size/2，取 0..24
判定线 y   = H × 0.79259
```

来源与复核：见 [01_独特思路.md](01_独特思路.md) 与 [03_验证记录.md](03_验证记录.md)。
`geometry/notes_geometry.json` 是"可替换的数据文件"：游戏大版本更新后用
`tools/reexport_scene.py` 重导一次并自动核对常数，不需要重打包。

## 5. 自检与诊断

* 启动自动只读自检：谱面 / 模板 / 手机 / 触摸屏节点 / 几何（约 1 秒，不碰手机画面）。
* 完整自检（选歌界面按 `c` 或 `--check`）：额外试建一次虚拟触摸屏，确认注入通道可用。
* 几何核对：把装有整屏截图的文件夹拖到 exe 上，程序自己量车道线间距与判定线并输出残差。
* 往返延迟：每次开演在加载页自动量，并把样本分布打进日志。

## 6. 打包（为什么是 onedir）

* PyInstaller **onedir**：`谛听.exe` + `_internal\`（Python + numpy + OpenCV）；
  发布形态只有"一个 exe + 几个文件夹"，**目标机器不需要装 Python**。
* 模板与 scrcpy-server 打包进 `_internal\tools\`；运行时先找 exe 旁边（方便你替换），再找包内那份。
* 谱面文件的时间戳是 1970 年，早于 zip 格式下限（1980）→ PowerShell 的 `Compress-Archive`
  会直接报错，所以 `tools/make_zip.py` 统一写固定时间戳。
