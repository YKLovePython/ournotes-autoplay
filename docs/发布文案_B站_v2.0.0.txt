【BanG Dream! Our Notes 自动演奏 v2.0 —— 真机、免 root、不用标定】

先说这一版和以前最大的不同：
**落点是「算」出来的，不是「量」出来的。**

我们从游戏自己的场景数据里读出了演奏区的几何：
判定线在屏高的 79.26%、谱面是 24 格（格距 0.64237 平面单位）、演奏相机 54°、
判定平面正好 1:1 铺在屏幕高度上。
于是"换一台手机要重新标定"这件事**从根上消失了** —— 程序按你屏幕的尺寸自己算。

（顺便说个实话：我们上一版正是踩了"从画面量几何"的坑 —— 判定线取错 44 像素、
横向偏宽 5.5%，导致最外侧那条轨道的落点偏 37 像素、偶尔会掉。
这次用 31 张实机无损截图让程序自己复核，车道线间距残差中位 **-1.1%**。）

【怎么用】四步

1. 打开电脑访问：
   https://github.com/YKLovePython/ournotes-autoplay/releases/latest
   （往下滑到 Assets → 点 Diting-OurNotes-Autoplay-v2.0.0-win64.zip，约 67MB）
   ※ GitHub 打不开就挂加速器；下完**一定要解压**再运行

2. 手机：设置 → 更多设置 → 开发者选项 → 打开「USB 调试」
   数据线连电脑；弹窗「允许 USB 调试吗」→ 勾「始终允许」→ 确定
   （小米/红米：拔插一次线；下拉通知栏选「传输文件」更稳）

3. 游戏里选好歌和难度，停在**有 LIVE START 的那一页**

4. 双击解压出来的「谛听.exe」→ 回车选歌 → 回车选难度
   演奏画面一出来，**按下第 1 个音符**（大部分是 1 个，有的是 2~3 个），按完松手 ——
   后面它自己打完。

————————————————————————

【这一版为什么只给一个 exe】

解压后你只会看到：
    谛听.exe  ＋  几个文件夹（_internal / config / geometry / work / platform-tools）

* **不用装 Python**（运行库都打包进去了），不用装任何环境；
* 没有 bat、没有配置向导：双击就是打歌；
* **自检内置**：启动时自动检查谱面/模板/手机/触摸屏/几何，哪一项不对直接告诉你怎么办；
  选歌界面按 `c` 是完整自检（会额外试建一次虚拟触摸屏）。

————————————————————————

【遇到问题】

打不开、认不出确认页、打不准 —— 都可以在群里问，
把「程序里那几行字」或日志发出来就行（日志在 logs 文件夹里），不用截图。

* 整体打早了（结算页 FAST 多）→ 打开 config\default.yaml，把 offset_ms 调大一点（比如 +20）
* 整体打晚了（SLOW 多）→ 调小一点（比如 -20）
  （单位毫秒，正数=提前；改完下一局生效，不用重装）

————————————————————————

【几句必须说的话】

* 本工具**只支持 Windows 电脑 + 安卓手机**（苹果电脑 / iPhone 用不了）；
* 免 root、不碰游戏内存、不改游戏文件 —— 借 scrcpy 的虚拟触摸屏（系统认成真外设）；
* 但它**仍然可能违反游戏服务条款**，有被限制/封号的风险：请别拿主力账号冒险，
  也不要在活动排名、竞技里用；
* 项目完全开源（含时间戳存证与独立验证方法），免费分享，
  如果你是被卖钱买到的，那说明被倒卖了，可以要求退款并举报。
